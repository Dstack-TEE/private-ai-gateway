# E2EE v2 Test Vectors

These vectors pin the RFC 8785 JCS associated-data bytes used by the
[E2EE v2 compatibility protocol](e2ee-v2.md). The values are regenerated by
[`tools/gen-vectors.py`](tools/gen-vectors.py), and the Rust and TypeScript
test suites pin the same constants.

## Fixed inputs

| Input | Value |
| --- | --- |
| Suite | `x25519-aes-256-gcm-hkdf-sha256` |
| Service X25519 private seed | 32 × `0x03` |
| Service X25519 public key | `5dfedd3b6bd47f6fa28ee15d969d5bb0ea53774d488bdaf9df1c6e0124b3ef22` |
| Model | `demo-model` |
| Request nonce | `000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f` |
| Request timestamp | `1750000000` |
| Response id | `chatcmpl-123` |

These vectors cover AAD construction. Field encryption still requires a fresh
ephemeral key and AES-GCM nonce for every field.

## Request field AAD

For `messages.0.content`, the JCS bytes are exactly:

```text
{"algo":"x25519-aes-256-gcm-hkdf-sha256","field":"messages.0.content","model":"demo-model","nonce":"000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f","purpose":"aci.e2ee.request.v2","ts":1750000000}
```
